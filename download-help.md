# The easiest choice: `Download MP3`.

An album downloads as one ZIP file containing all the songs. After it finishes downloading, you need to extract/unzip it once. Then the songs are ordinary MP3 files you can play with your favorite music app.

# Start Here: Download the Album
Tap `Download MP3` → on the MEGA page choose Download. You do NOT need to install the MEGA app, nor do you need a MEGA account.

### Android phone/tablet
Open Files/Downloads → tap the ZIP → Extract → open the resulting folder with your music player.

#### Don't see the music in your music app?

Make sure you extracted the ZIP file first. Your music player should then find the MP3 files automatically.

### iPhone/iPad
Open the ZIP from Files → tap the ZIP to extract it → play/import the MP3 files from there.

### Windows
Open Downloads folder → right-click ZIP → Extract All → play the MP3 files.

### Mac
Open Downloads → double-click ZIP → play the extracted files in your preferred player.

### Ok, Take Me Back!
<button onclick="window.close()">Close this page and return to the album</button>

If the button doesn't work, simply close this browser tab. Your album page is still open in the previous tab.

# Frequently Asked Questions

### Why did this take me to MEGA?
I use MEGA to host the larger album download files. You're still downloading my music; MEGA is simply where the file is stored.

### What is FLAC?
FLAC is just a different audio file type that preserves the original audio without lossy compression. You can use these if you know what you're doing and prefer to. However, the MP3 files are also very high quality, much smaller in size, and compatible across more devices. Most people won't be able to tell the difference.

### Alternatives
You can also use the AudioMack app on your device to download albums or individual songs. I have not done this myself, so I am not familiar with exactly how it works.
